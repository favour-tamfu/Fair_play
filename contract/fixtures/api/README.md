# API fixtures — FAKE data for web development only

Sample responses of the read API (contract §6) for `web/…?mock=1`. Generated by `python -m server.tools.make_api_fixtures`
(deterministic); every file is validated against `contract/schemas/` by `server/tests/test_api_fixtures.py`.

- Names are fake ("Mock Song 001", "Mock Artist 01", "Mock Bar …"); numbers are illustrative and **must never appear in the pitch**.
- Self-consistent: shares sum to 1, `amount_fcfa` and payouts sum exactly to the 100,000,000 FCFA pot, plays are newest first,
  the loop song `S-M0015` is #1 in `shares_raw.json` and drops after standardisation (`shares_standardised.json`).
- `feed_sample.txt` is raw Server-Sent-Events text with one or more events of every type (batch, match, play, flag, ledger, meter, stats).
